# HostelHub – Hostel Management System

## Project Introduction
HostelHub is a web-based Hostel Management System developed
to simplify and manage daily hostel operations.

The application helps hostel administrators manage student
records, room allocation, payments, complaints, and staff
information through a centralized dashboard.

## Objectives
- Manage student information.
- Add and manage hostel rooms.
- Maintain payment records.
- Track student complaints.
- Manage hostel staff details.
- Update hostel information.
- Manage dropdown options from settings.

## Installation and Setup

### 1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Open the project folder
cd HostelHub

### 3. Create virtual environment
python -m venv venv

### 4. Activate virtual environment

Windows:
venv\Scripts\activate

### 5. Install dependencies
pip install -r requirements.txt

### 6. Run the application
python app.py

### 7. Open in browser
http://127.0.0.1:5000

## Database
The project uses SQLite.
The database is created locally when the application runs.
